# lide100-sane-fixes

اصلاحات **غیررسمی** برای اسکنر **Canon CanoScan LiDE 100** در لینوکس، به‌صورت وصله برای درایور genesys در SANE. این پروژه هیچ ارتباطی با شرکت کانن ندارد.

[English](README.md)

## چه مشکلاتی را حل می‌کند

- **نوارهای زرد عمودی** در اسکن رنگی.
- **نقطه‌های قرمز، زرد و صورتی** روی لبه‌های براق، مثل لبه‌ی کارت‌های پلاستیکی.
- **رنگ‌های مات و کم‌جان** در مقایسه با درایور ویندوز کانن.

علت‌ها با ضبط ترافیک USB درایور ویندوز کانن پیدا شد و در [docs/FINDINGS.md](docs/FINDINGS.md) (به انگلیسی) توضیح داده شده است. به‌طور خلاصه:

- درایور SANE آخرین خانه‌ی جدول گاما را صفر می‌گذارد، پس هر رنگی که به نهایت روشنایی برسد سیاه می‌شود.
- نوار سفید کالیبراسیون داخل اسکنر با گذشت زمان زرد می‌شود.
- تنظیمات نور و گامای SANE با درایور کانن فرق دارد.

## وصله‌ها

- **وصله‌ی ۰۰۰۱:** آخرین خانه‌ی جدول گاما را حداکثر می‌گذارد. احتمالاً برای همه‌ی مدل‌های LiDE کانن با تراشه‌ی GL847 یا GL124 مفید است.
- **وصله‌ی ۰۰۰۲:** نوردهی لامپ‌ها، میانگین‌گیری پیکسل‌ها و گاما را مثل درایور ویندوز می‌کند. مخصوص LiDE 100.
- **وصله‌ی ۰۰۰۳:** تصحیح ستون‌به‌ستون برای نوار سفید زردشده. مخصوص LiDE 100.
- **وصله‌ی ۰۰۰۴:** ذخیره‌ی تصاویر اشکال‌زدایی به‌صورت PNM وقتی libtiff نصب نیست. ابزار ساخت پروفایل به آن نیاز دارد.

## نصب

روی دبیان (sid) با sane-backends نسخه‌ی 1.4.0 آزمایش شده است. درایور اصلاح‌شده در پوشه‌ی `~/.local/lib/sane-lide100` نصب می‌شود و SANE سیستم دست نمی‌خورد.

۱. نصب ابزارهای ساخت:

```bash
sudo apt install build-essential autoconf automake autoconf-archive libtool autopoint gettext pkg-config libusb-1.0-0-dev dpkg-dev zenity imagemagick
```

۲. ساخت درایور. بدون ورودی، سورس را با `apt-get source sane-backends` می‌گیرد (به خطوط deb-src در تنظیمات APT نیاز دارد). می‌توانید مسیر یک سورس sane-backends 1.4.0 را هم بدهید:

```bash
scripts/build.sh
```

۳. نصب اسکریپت‌ها و میانبرهای منو، با نام‌ها و پیام‌های فارسی:

```bash
LIDE100_LANG=fa scripts/install.sh
```

۴. یک **برگه‌ی A4 سفید، تمیز و بدون نوشته** را صاف روی شیشه بگذارید. هیچ چیز دیگری زیر یا کنار آن نباشد. درِ اسکنر را ببندید و پروفایل نوار سفید اسکنر خودتان را بسازید (حدود یک و نیم دقیقه). اگر کاغذ یکنواخت به نظر نرسد، ابزار پروفایل را ذخیره نمی‌کند:

```bash
lide100-strip-profile.py
```

## استفاده

- **برنامه‌ی «اسکنر اسناد (کانن LiDE 100)»** در منوی برنامه‌ها: همان Document Scanner گنوم، با درایور اصلاح‌شده. برنامه‌ی Document Scanner معمولی همچنان از درایور سیستم استفاده می‌کند.
- **میانبر «اسکن رنگی»:** رزولوشن را می‌پرسد، تصویر را با فرمت JPEG در `~/Pictures/Scans` ذخیره و باز می‌کند. از ترمینال: `SCAN_RESOLUTION=600 scan-color`
- **هر برنامه‌ی دیگر SANE:** با `lide100-env` اجرا کنید، مثلاً `lide100-env scanimage -L`

اگر نوارها دوباره پیدا شدند (مثلاً بعد از تمیز کردن اسکنر)، پروفایل را دوباره بسازید.

## محدودیت‌ها

فقط روی یک دستگاه و با رزولوشن ۱۵۰ و ۳۰۰ آزمایش شده است. مقادیر نوردهی و گاما از درایور ویندوز همان دستگاه گرفته شده‌اند. گزارش صاحبان دیگر LiDE 100، و برای وصله‌ی ۰۰۰۱ صاحبان مدل‌های دیگر LiDE، خوشحالمان می‌کند.

## ابزارها

پوشه‌ی `tools` ابزارهایی را دارد که برای پیدا کردن این مشکلات به کار رفت: اجرای ویندوزِ نصب‌شده روی همان کامپیوتر داخل QEMU به‌صورت فقط‌خواندنی، با دادن اسکنر به آن و ضبط ترافیک USB، و یک برنامه برای خواندن فایل‌های ضبط. این فایل‌های ضبط را هرگز منتشر نکنید، چون تکه‌هایی از تصویرهای اسکن‌شده در آن‌هاست.
